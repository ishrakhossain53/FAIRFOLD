{% extends "base.html" %} {% comment %} Page #4 (design.md S04): the public job board. **One GET, no HTMX.** design.md S04 asks for `hx-push-url` so Back restores the filters. A normal GET form already does that, works on a first load with no JavaScript, and keeps the result region a server-rendered list a screen reader can announce. Adding an HTMX partial here would duplicate the card markup for a page whose latency budget is one query set. **Search and filters are two forms on purpose.** The search bar is above the results and the filters are in the sidebar; one form would have to wrap the results to keep the layout. Each form carries the other's current values as hidden inputs, so pressing Search does not silently drop the level filter. **The mobile sheet is a visible card.** A bottom sheet needs JavaScript to open, trap focus and close, and the same fields fit above the results at 360px. The fieldsets are the same ones the desktop sidebar uses; only the position changes. {% endcomment %} {% block title %}Find jobs · FairFold{% endblock %} {% block description %}Browse active jobs on FairFold.
