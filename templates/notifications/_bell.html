{% comment %} The header bell (design.md §5.4 "Header: logo · global search · 🔔 notifications · account ▾" and W19). Rendered by `templates/base.html` only for a signed-in user. The unread count comes from `notifications.context_processors.unread_notification_count`, which returns zero for anonymous requests, so no page has to pass it in. Accessibility (W19): the count is in the link's accessible name ("Notifications, 3 unread"), not conveyed only by the badge colour or by the icon. Screen-reader users therefore hear the state without having to interpret a dot, and the badge itself is `aria-hidden` so it is not read twice.
