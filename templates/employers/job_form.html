{% extends "base.html" %} {% comment %} Page #36 (design.md S11): create or edit a draft job. **Why one page and not S11's five-step stepper.** Every section here is part of one form and one save. A stepper without per-step validation only hides fields and adds a state machine the server would have to trust; the section links below scroll instead. The sections themselves are S11's: Basics, Description, Requirements, Review. **What is not on the page, and why** (also in `JobForm`): * AI-suggested skills and questions -- Phase 2 (REQ-FR-025's second clause); * structured required/nice-to-have skills -- `job_skills` has no model yet, so the free-text requirement fields are what the ranker can read; * screening questions -- no document defines the JSONB element shape, and the API refuses the field for the same reason; * required assessments -- REQ-FR-051 has no model yet; * Scorecard Criteria Publish (design.md 7.21) -- no batch has built it. Auto-save exists only once the draft row exists. On the create page there is no id to POST to, so the first save is the Save draft button. {% endcomment %} {% block title %}{% if job %}Edit {{ job.title }}{% else %}New job{% endif %} · FairFold{% endblock %} {% block content %}
