{% extends "base.html" %} {% comment %} Page #29 — Application detail (design.md §10.0 row 29, wireframe S07, REQ-FR-023, batch 1.39). Deviations from the wireframe, all deliberate and reported with the batch: * **The score card is a Phase-1 slot.** REQ-FR-024 is Phase 2: nothing writes `match_score` yet. The card says "Not screened yet" instead of drawing an empty score, a bias badge, matched/missing skills or an expandable rationale -- all of which need the screening payload (2.21-2.25) and would be invented here. * **"View my story for this job" and "Message the employer" are absent.** They are REQ-FR-016/017 (Phase 3) and REQ-FR-043 (Phase 2) and would be dead controls. No notification link either (batch 1.43). * **The stepper has six steps, not five.** S07 stops at "Offered"; `hired` is in the model's pipeline and an application that reached it must not render as if "Offered" were still the last stage. * `rejected` and `not_matched` are not steps. Gap G3 says `not_matched` is a filter outcome the employer can review and pull back, not a rung on the same ladder, and `rejected` is a closed outcome. {% endcomment %} {% block title %}Application · {{ application.job_title }} · FairFold{% endblock %} {% block content %}
