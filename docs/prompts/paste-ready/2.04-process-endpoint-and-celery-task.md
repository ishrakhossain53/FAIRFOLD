# Batch 2.4: Process endpoint and Celery task

**Phase:** Phase 2: AI screening pipeline  
**Type:** backend+tests  
**Requirement and source refs:** REQ-FR-012; POST /api/v1/candidates/resumes/{id}/process/  
**Recommended prerequisite:** 2.3 (Extraction edge cases)

## In scope
- Owner-only endpoint queuing a Celery task: fetch from storage, extract, update status. Idempotent on repeat.
- Raw extracted text is held in memory only; it must never be stored before PII stripping (the DDL stores only PII-stripped text).

## Out of scope

## Done when
