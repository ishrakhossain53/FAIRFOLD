# Batch 2.6: PII test dataset and accuracy harness

**Phase:** Phase 2: AI screening pipeline  
**Type:** tests  
**Requirement and source refs:** REQ-FR-011, REQ-FR-057; Arch Doc §10 Phase 2 (95%+ accuracy)  
**Recommended prerequisite:** 2.5 (Extraction status UI)

## In scope
- Synthetic labelled resumes (names, emails, phones, addresses, institutions, employers, age dates, URLs) under tests/pii/vX.Y.Z/ with a manifest, following the structure of tests/bias/.
- Harness that computes recall per category and a keep-set check (skills and experience must survive).
- A verification script in scripts/ and a CI step, mirroring verify_bias_set.py.

## Out of scope
- The stripping implementation.

## Done when
- Harness runs against a trivial baseline and reports numbers honestly.

## Watch out
- Never fabricate results. Report measured values and the dataset size.
