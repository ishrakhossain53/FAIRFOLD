# Batch 2.3: Extraction edge cases

**Phase:** Phase 2: AI screening pipeline  
**Type:** backend+tests  
**Requirement and source refs:** REQ-FR-012  
**Recommended prerequisite:** 2.2 (PDF text extraction service)

## In scope
- Unsupported type, empty PDF, malformed PDF, password-protected, scanned image-only PDF (no text layer) each produce a distinct, actionable failure code.
- Page and size limits to prevent decompression-bomb style abuse.

## Out of scope
- OCR (not in scope for the MVP unless the docs say so).

## Done when
- One test per failure code with a user-safe message.
